# NexaGrid – Releases

**Offizielle Download-Seite: https://nexa-grid-hub.base44.app/downloads**

Dieses Repository enthält nur die fertigen Versionen von **NexaGrid** (eine inoffizielle Fan-Mod für Hytale von TC-Maker)
und der Begleit-Mod **ModPerformanceMonitor**, dazu die Daten für Website und Wiki. Der Quellcode ist nicht öffentlich.

- `NexaGrid-<Version>.jar` und `ModPerformanceMonitor-<Version>.jar` liegen unter *Releases*.
- NexaGrid braucht den ModPerformanceMonitor (≥ 1.1.0). Beide Dateien in den Mods-Ordner deines Hytale-Servers bzw. deiner Welt legen.
- Fehler und Ideen bitte über https://nexa-grid-hub.base44.app/melden melden.
- Das Release `site-data` enthält die Daten für Website und Wiki (kein Download zum Spielen).
