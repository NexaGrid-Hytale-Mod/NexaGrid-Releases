# NexaGrid – Releases

**Offizielle Seite und Downloads: https://nexa-grid.net/downloads**

Dieses Repository enthält nur die fertigen Versionen von **NexaGrid** (eine inoffizielle Fan-Mod für Hytale von TC-Maker)
und der Begleit-Mod **ModPerformanceMonitor**, dazu die Daten für Website und Wiki. Der Quellcode ist nicht öffentlich.

## Herunterladen

- **Aktuelle Version: Alpha 0.17.3** – [Releases → Latest](https://github.com/NexaGrid-Hytale-Mod/NexaGrid-Releases/releases/latest),
  Datei `NexaGrid-0.17.3-alpha.jar`. Ältere Versionen sind vorerst offline. Die Downloadseite der Website zeigt immer die
  freigegebene Version.
- **Installation:** die `.jar` in den Mods-Ordner deines Hytale-Servers bzw. deiner Welt legen, Mod aktivieren, Welt starten.
  Unterstützt: Hytale 0.7.0 – 0.8.x.
- **ModPerformanceMonitor** ist seit 0.15 in NexaGrid eingebaut (`/perf`) und wird nicht mehr gebraucht. Die eigenständige
  Mod (`perfmon-v…`) bleibt für Server ohne NexaGrid.
- Die Versionen zählen seit 0.15.1 als `0.MINOR.PATCH-alpha` (Anzeige „Alpha 0.17.3“). Die alten Nummern 3.11.x – 3.12.x
  sind ältere Alpha-Builds derselben Mod.

## Auf der Website

- **Wiki** (https://nexa-grid.net/wiki): alle Säulen, Bereiche, Kapitel und Quests, dazu **Items & Rezepte** – jedes Item
  mit Beschreibung wie im Spiel, Werkbank, Zutaten, Aufwertung, Schmelzen, Verwendung und Fundorten.
- **Patchnotes** (https://nexa-grid.net/patchnotes): jede Version DE/EN.
- **Webkarte** (https://nexa-grid.net/karte, nach Anmeldung und `/ng web verbinden` im Spiel): Hytales eigene Kartenbilder
  bis 3 Pixel je Block, alle Ebenen der Ingame-Karte (Heime, Warps, Wegpunkte, Gräber, Dungeons, Orte, Dörfer, Portale,
  Party, Grundstücke), deine Position live mit Blickrichtung, „Mir folgen“, Vollbild und „Bildschirm wach halten“ – gedacht als
  zweiter Bildschirm oder Tablet neben dem Spiel. Rechtsklick setzt einen Wegpunkt im Spiel.
- Fehler und Ideen bitte über https://nexa-grid.net/melden melden.

Das Release `site-data` enthält die Daten für Website und Wiki (kein Download zum Spielen).
